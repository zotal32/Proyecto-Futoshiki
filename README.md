# Proyecto Futoshiki

Este proyecto es una implementación en Haskell relacionada con el juego lógico Futoshiki. 
Se incluye un script en Python para la generación de juegos de prueba.

## Archivos principales
* `Main.hs` y `Futoshiki.hs`: Código fuente en Haskell.
* `creadorJuegosDePruebasTLP.py`: Script de Python para generar juegos de prueba.
* `TestTLP2026Students.txt`: Juego de pruebas inicial.

## Cómo ejecutarlo
1. Asegúrate de tener instalado GHC.
2. Compila el archivo principal: `ghc Main.hs`
3. Ejecuta la funcion main una vez que accedas: `main`
4. Introduce el juego de pruebas que quieras poniendo su nombre con su extensión

Tambien si compilas el archivo Futoshiki.hs y usas la función solve puedes conseguir resolver cualquier futoshiki
proporcionando el futoshiki a resolver por parámetro, recomiendo primero guardarlo en una variable y ejecutar la
función metiendo de parámetro la variable.
